About Me

Hi! I'm the creator of this website. This project was built to practice responsive web design using Bootstrap for the navigation bar, and Flexbox and CSS Grid for building a responsive photo gallery.

The site is fully responsive, meaning it works well on mobile phones, tablets, and desktop screens. Try resizing your browser window to see the layout adapt!

Feel free to explore the Photos page to see the gallery in action, or leave a note on the Feedback page.
